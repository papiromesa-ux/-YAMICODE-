El mensajero y la torre

El envío de datos

Cuando visitas una página, el navegador (el mensajero) solicita archivos a un servidor (la torre). Para que Alexander pueda enviarle un mensaje a Andrea, necesita guardar la dirección del servidor de ella en una variable.

Instrucción:

Crea una constante llamada direccion y asígnale el texto https://yamicode.web usando comillas dobles.
