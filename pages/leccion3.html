El mapa de la respuesta

El código 200

Cuando Andrea (el servidor) recibe el mensaje de Alexander, responde con un estado. Si todo salió bien, el estado es 200. Vamos a programar una condición (if) para que, si el estado es 200, el sistema muestre un mensaje de éxito.

Instrucción:

Escribe el siguiente bloque de código exacto:

const estado = 200;
if (estado === 200) {
  console.log("Respuesta recibida");
}
