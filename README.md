# <YAMICODE>

Plataforma web educativa enfocada en la enseñanza de programación, hacking ético y creación de software, con una estética visual Cyberpunk/Anime.

## Características actuales
- Diseño responsivo (adaptado para celulares y computadoras).
- Módulos de Aulas (Lenguajes de programación).
- Especialidades (Ciberseguridad, Hackodeo, Gamercraft).
- Minijuegos interactivos.
- Panel de perfil del estudiante.

## Tecnologías
- HTML5
- CSS3
- JavaScript (Vanilla)

## Estado del Proyecto
En desarrollo activo - Release 1.
